# Root responsibilities

Confirm explicit user invocation and applicable session rules, then read `fleet-orchestrator`.
Root is the existing parent session. Do not create `root.toml`. Keep the source of truth for the common contract and model mapping in the Kit.
While delegating independent research, continue unassigned decisions, contract work, and integration preparation. Do not duplicate the same research.
Only one writer, including Root, may edit a worktree. Stop editing before verification or review begins.
Diagnose when parent permissions can override child settings. Do not begin a risky test when permissions cannot be assured.
Only Root updates the work ledger. Check child results against the current contract and execution evidence, and close unnecessary children after acceptance.
When the runtime has no close API, retain that limitation. Do not treat completion or interruption as evidence of close.
